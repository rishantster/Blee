# Blee

Blee is an Android-first payment app designed to keep payments moving across online, local Wi-Fi, and Bluetooth connectivity.

## Product direction

- APK-first Android product
- Native SQLite is the durable source of truth for payment state
- Self-custodial wallet security
- Nearby transport over LAN/BLE with onchain settlement
- Explicit pending vs confirmed balances

This repository replaces the earlier ARC DROP prototype workspace for all future Blee builds.
